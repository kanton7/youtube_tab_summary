태그 한 번 툭 — 개인정보처리방침

시행일 2026년 8월 29일 · 최종 수정일 2026년 8월 29일

Read in English

요약. 이 확장 프로그램은 개발자나 제3자에게 어떠한 정보도 수집하거나 전송하지 않습니다. 사용자가 담은 영상 목록은 사용자의 브라우저 안에만 저장되며, 계정·로그인·서버가 없습니다.

1. 수집하는 정보

이 확장 프로그램은 개인정보를 포함한 어떠한 정보도 수집하지 않습니다. 개발자가 운영하는 서버가 없으며, 분석 도구나 광고 모듈을 포함하지 않습니다. 사용자의 데이터가 사용자의 기기를 떠나는 경로 자체가 존재하지 않습니다.

2. 기기에 저장되는 정보

사용자가 확장 프로그램 아이콘을 클릭하고 태그를 눌러 직접 담기를 실행한 유튜브 영상에 한해, 아래 정보가 사용자의 브라우저 안에 저장됩니다.

영상

항목내용
id유튜브 영상 고유 번호
url영상 주소
title영상 제목
channel채널명 (가져올 수 있는 경우에만, 없으면 빈 값)
thumbnail썸네일 이미지의 주소 (이미지 파일 자체는 저장하지 않음)
tagIds사용자가 붙인 태그의 번호
savedAt담은 시각
source담은 경로 (현재는 항상 “팝업”)

태그

항목내용
id태그 고유 번호
name사용자가 직접 입력한 태그 이름
pinned즐겨찾기 고정 여부
useCount사용 횟수 (팝업에서 태그를 정렬하는 데 사용)
lastUsedAt마지막으로 사용한 시각

사용자가 방문한 페이지의 기록, 검색어, 클릭이나 마우스 움직임 같은 활동 정보는 저장하지 않습니다. 사용자가 담기를 실행하지 않은 영상은 어떤 형태로도 기록되지 않습니다.

3. 저장 위치와 보관 기간

위 정보는 크롬이 확장 프로그램에 제공하는 로컬 저장 공간(chrome.storage.local)에 저장됩니다. 이 저장 공간은 사용자의 컴퓨터 안에 있으며, 개발자를 포함한 누구도 외부에서 열람할 수 없습니다.

사용자가 보관함에서 개별 영상을 삭제하면 그 기록은 즉시 사라집니다. 확장 프로그램을 삭제하면 저장된 모든 데이터가 함께 삭제됩니다. 별도의 보관 기간을 두지 않으며, 개발자가 백업을 보관하지 않습니다.

4. 외부로 나가는 통신

이 확장 프로그램은 개발자의 서버와 통신하지 않습니다. 외부로 나가는 요청은 아래 한 가지뿐입니다.

  • 썸네일 이미지 표시 — 저장한 영상의 썸네일을 화면에 보여주기 위해 유튜브(img.youtube.com)에 이미지를 요청합니다. 이때 전송되는 것은 이미지 주소뿐이며, 사용자의 태그·저장 목록·개인정보는 포함되지 않습니다. 이 요청은 사용자가 팝업이나 보관함 화면을 열었을 때 브라우저가 일반적인 이미지 로딩과 동일하게 수행합니다.

보관함에서 영상 카드를 클릭하면 새 탭에서 유튜브가 열립니다. 이는 일반적인 링크 이동이며, 확장 프로그램이 별도로 정보를 전송하는 것이 아닙니다.

5. 권한별 사용 목적

이 확장 프로그램은 아래 권한만 요청합니다. 특정 사이트에 상시 접근하는 호스트 권한 (host_permissions)은 요청하지 않으며, 항상 실행되는 콘텐츠 스크립트도 포함하지 않습니다.

권한사용 목적
activeTab 사용자가 아이콘을 클릭한 그 순간의 탭에서 주소와 제목을 읽어 어떤 영상인지 확인합니다. 클릭하지 않으면 어떤 페이지에도 접근하지 않습니다.
scripting 아이콘을 클릭한 순간, 해당 유튜브 페이지에서 채널명 한 줄만 읽어옵니다. 페이지를 변경하지 않으며, 채널명을 찾지 못하면 빈 값으로 두고 넘어갑니다.
storage 담은 영상과 태그를 사용자의 브라우저에 저장합니다.
unlimitedStorage 담은 영상이 많아졌을 때 기본 저장 한도에 막히지 않도록 합니다.
contextMenus 확장 프로그램 아이콘의 우클릭 메뉴에 “보관함 열기” 항목 하나를 추가합니다. 웹페이지의 우클릭 메뉴는 변경하지 않습니다.

6. 제3자 제공 · 판매

수집하는 정보가 없으므로 제3자에게 제공하거나 판매하는 정보도 없습니다. 데이터를 신용도 평가나 대출 목적으로 사용하지 않으며, 승인된 용도 외로 사용하지 않습니다.

7. 원격 코드

이 확장 프로그램은 원격 코드를 사용하지 않습니다. 모든 자바스크립트, 스타일시트, 글꼴, 아이콘이 패키지 안에 포함되어 있으며, 외부에서 코드를 내려받아 실행하지 않습니다.

8. 계정과 아동

회원가입, 로그인, 기기 간 동기화 기능이 없습니다. 사용자를 식별하지 않으므로 연령 정보를 포함한 어떠한 개인정보도 수집하지 않으며, 아동을 대상으로 정보를 수집하는 기능이 없습니다.

9. 방침 변경

이 방침이 변경되면 이 페이지를 갱신하고 위의 최종 수정일을 바꿉니다. 데이터 처리 방식에 실질적인 변화가 생기는 경우 확장 프로그램 업데이트 설명에도 함께 안내합니다.

Privacy Policy — Tag Han Beon Tuk

Effective August 29, 2026 · Last updated August 29, 2026

Summary. This extension does not collect or transmit any information to the developer or any third party. Everything a user saves is stored only in the user's own browser. There are no accounts, no logins, and no servers.

1. Information We Collect

This extension collects no information of any kind, personal or otherwise. The developer operates no server, and the extension contains no analytics or advertising code. There is no mechanism by which user data can leave the user's device.

2. Information Stored on Your Device

Only for YouTube videos that the user explicitly saves — by clicking the extension icon and then clicking a tag — the following is stored inside the user's browser:

  • Video — video ID, URL, title, channel name (when available), thumbnail URL (not the image file itself), the tags applied by the user, the time it was saved, and the save source.
  • Tag — tag ID, the name the user typed, whether it is pinned, a use count, and the time it was last used. The use count is used only to order tags in the popup.

Browsing history, search terms, and activity such as clicks or mouse movement are not stored. Videos the user did not explicitly save are never recorded.

3. Where It Is Stored and For How Long

This data is stored in the local storage area Chrome provides to extensions (chrome.storage.local), which resides on the user's own computer. Nobody, including the developer, can read it remotely.

Deleting a video in the library removes its record immediately. Uninstalling the extension deletes all stored data. No retention period applies and the developer keeps no backups.

4. Outbound Network Requests

The extension never contacts a developer-operated server. There is exactly one outbound request:

  • Thumbnail images — to display the thumbnail of a saved video, the browser requests an image from YouTube (img.youtube.com). Only the image URL is sent; no tags, saved list, or personal data is included. This happens the same way any ordinary image on a web page loads.

Clicking a card in the library opens YouTube in a new tab. That is ordinary link navigation, not a transmission of data by the extension.

5. Permissions and Why They Are Needed

The extension requests only the permissions below. It requests no broad host permissions (host_permissions) and registers no persistent content scripts.

PermissionPurpose
activeTab Reads the URL and title of the active tab at the moment the user clicks the extension icon, to identify which video is being saved. Without a click, no page is accessed.
scripting On that same click, reads only the channel name from the YouTube page. It does not modify the page, and proceeds with an empty value if the name is not found.
storage Stores saved videos and tags in the user's browser.
unlimitedStorage Prevents the default storage quota from blocking saves once many videos have accumulated.
contextMenus Adds a single “Open library” item to the right-click menu of the extension icon. It does not alter the right-click menu of web pages.

6. Sharing and Sale of Data

Because no data is collected, none is shared with or sold to third parties. Data is not used for creditworthiness or lending purposes, and is not used for any purpose beyond the single purpose described in the store listing.

7. Remote Code

This extension does not use remote code. All JavaScript, stylesheets, fonts, and icons are bundled in the package. Nothing is downloaded and executed at runtime.

8. Accounts and Children

There is no sign-up, login, or cross-device synchronization. The extension does not identify users and collects no personal information, including age, and has no feature that collects information from children.

9. Changes to This Policy

If this policy changes, this page will be updated and the “last updated” date above will change. Any material change to how data is handled will also be noted in the extension's update description.
